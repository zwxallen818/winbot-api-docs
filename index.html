预研机遥控协议

方向控制 + 吸附风机 + 滚刷

通用说明

所有指令通过蓝牙发送，框架自动注入两个字段：

字段类型说明
tsnumberUnix 秒级时间戳
seqnumber0~999 循环递增的序列号

Hardware 协议规范

所有硬件控制指令统一使用 hardware 键包裹，收发结构一致：

方向Topic数据结构
发送 setProperties { hardware: { 模块名: { ... } } }
接收 onProperties { hardware: { 模块名: { ... } } }
重要：onProperties 是设备主动上报的状态变更通知，结构为 { hardware: { suction_fan: {...}, roller_brush: {...}, ... } }， H5 收到后按 hardware.模块名 路径读取并更新 UI。

move 不加密；setProperties 和 onProperties 在固件 > 1.2.5 时会 AES-CCM 加密后再传输。

1. 方向移动 move

Topicmove
加密否
策略按下即刻发一条，然后每 100ms 轮询；松手停止

Payload

参数类型取值
actstringforward | backward | left | right
外窗模式：left ↔ right 自动互换，forward/backward 不变。 
// 完整 payload（ts/seq 框架自动加）
{ "act": "forward", "ts": 1768363200, "seq": 41 }
{ "act": "left",    "ts": 1768363201, "seq": 42 }
{ "act": "right",   "ts": 1768363202, "seq": 43 }
{ "act": "backward","ts": 1768363203, "seq": 44 }

2. 吸附风机 setProperties → hardware.suction_fan

TopicsetProperties
数据路径hardware.suction_fan
加密固件 > 1.2.5 时加密
策略用户操作开关时单次发送，全量覆盖

发送 Payload

参数类型取值说明
enablenumber0 | 10=关，1=开
vacuum_levelnumber1 ~ 5吸力档位，默认 3
// 发送 — 打开吸附风机
sendBluetoothData('setProperties', {
  hardware: { suction_fan: { enable: 1, vacuum_level: 3 } }
})

// 发送 — 关闭
sendBluetoothData('setProperties', {
  hardware: { suction_fan: { enable: 0, vacuum_level: 3 } }
})

接收 onProperties 响应

// 设备上报 — 结构与发送一致，从 hardware.suction_fan 读取
{
  "hardware": {
    "suction_fan": { "enable": 1, "vacuum_level": 3 }
  }
}

3. 滚刷 setProperties → hardware.roller_brush

TopicsetProperties
数据路径hardware.roller_brush
加密固件 > 1.2.5 时加密
策略用户操作时单次发送，全量覆盖

发送 Payload

参数类型取值说明
enablenumber0 | 10=关，1=开
directionnumber1 | 21=正转，2=反转
indexnumber1 | 21=前滚刷，2=后滚刷
speed_levelnumber1 ~ 10转速档位，实际 RPM = 档位 × 10，默认 6 (60rpm)
// 发送 — 前滚刷正转，6档（60rpm）
sendBluetoothData('setProperties', {
  hardware: { roller_brush: { enable: 1, direction: 1, index: 1, speed_level: 6 } }
})

// 发送 — 后滚刷反转，8档（80rpm）
sendBluetoothData('setProperties', {
  hardware: { roller_brush: { enable: 1, direction: 2, index: 2, speed_level: 8 } }
})

// 发送 — 关闭滚刷
sendBluetoothData('setProperties', {
  hardware: { roller_brush: { enable: 0, direction: 1, index: 1, speed_level: 6 } }
})

接收 onProperties 响应

// 设备上报 — 结构与发送一致，从 hardware.roller_brush 读取
{
  "hardware": {
    "roller_brush": { "enable": 0, "direction": 1, "index": 1, "speed_level": 6 }
  }
}

4. 设备上报 onProperties（完整示例）

TopiconProperties
方向设备 → H5（主动推送）
加密固件 > 1.2.5 时加密
触发时机设备状态变化时主动上报

完整 Payload 结构

{
  "hardware": {
    "suction_fan":  { "enable": 1, "vacuum_level": 3 },
    "roller_brush": { "enable": 1, "direction": 1, "index": 1, "speed_level": 6 },
    "water_pump":   { "enable": 0, "spray_amount": 3, "work_interval": 5, "stop_interval": 3 },
    "drive_motor":  { "enable": 1, "speed_level": 5 },
    "pressure": 1,
    "current": 1
  }
}
H5 侧处理：收到 onProperties 后， 从 data.hardware.模块名 路径读取各模块状态， 深度合并入本地 store.Properties.hardware，触发 UI 更新。
